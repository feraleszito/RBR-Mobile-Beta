# RBR Mobile — Installation Guide / Guía de instalación

## English

### Requirements

- A compatible iPhone or iPad.
- A Windows PC or Mac.
- A USB cable.
- An Apple Account for signing the application.
- [Sideloadly](https://sideloadly.io/).
- The RBR Mobile Beta IPA, once published in GitHub Releases.
- Required Richard Burns Rally game resources obtained legitimately.

**Important:** The app interface is currently in Spanish.

### Install the IPA

1. Download `RBR-Mobile-Beta.ipa` from the latest GitHub Release.
2. Install and open Sideloadly on your computer.
3. Connect your iPhone or iPad via USB and trust the computer if prompted.
4. Select your device in Sideloadly.
5. Drag the IPA into Sideloadly.
6. Enter the Apple Account used to sign the app and start the installation.
7. Follow any additional signing or device verification instructions shown by Sideloadly.
8. On iOS, enable Developer Mode if required, then authorize the installed app using the applicable device settings.
9. Launch RBR Mobile.

### Game resources

The IPA does not include the original Richard Burns Rally game resources.

The application expects the required game resources in its accessible `RBR` directory.

Once the app has created its folder in the Files app, the intended location is:

`On My iPhone / RBR Mobile / RBR`

or

`On My iPad / RBR Mobile / RBR`

**Note:** Depending on the installed build, the application folder may appear as `ReRBRProbe` rather than `RBR Mobile`. Use the actual folder created by your installation.

Copy your legitimately obtained, compatible resources into that folder, keeping their directory structure intact. Do not rename internal game folders or files.

The exact required resource set and supported installation methods will be documented as testing progresses.

### Important notes

- Free Apple Accounts may require the application to be signed again after approximately seven days.
- Performance varies by device.
- Some vehicles and stages may require additional compatible resources.
- Do not redistribute copyrighted game resources without authorization.

## Español

### Requisitos

- Un iPhone o iPad compatible.
- Un computador con Windows o Mac.
- Un cable USB.
- Una cuenta de Apple para firmar la aplicación.
- [Sideloadly](https://sideloadly.io/).
- El archivo IPA de RBR Mobile Beta, cuando esté disponible en GitHub Releases.
- Los recursos necesarios de Richard Burns Rally obtenidos legítimamente.

**Importante:** La interfaz de la aplicación está actualmente en español.

### Instalar la IPA

1. Descarga `RBR-Mobile-Beta.ipa` desde la última versión publicada en GitHub Releases.
2. Instala y abre Sideloadly en tu computador.
3. Conecta tu iPhone o iPad por USB y autoriza el computador si aparece el aviso.
4. Selecciona tu dispositivo en Sideloadly.
5. Arrastra la IPA a Sideloadly.
6. Introduce la cuenta de Apple que utilizarás para firmar la aplicación e inicia la instalación.
7. Sigue las instrucciones adicionales de firma y verificación que aparezcan.
8. Si iOS lo solicita, activa el modo desarrollador y autoriza la aplicación desde los ajustes correspondientes.
9. Abre RBR Mobile.

### Archivos del juego

La IPA no incluye los recursos originales de Richard Burns Rally.

La aplicación necesita encontrar los recursos compatibles dentro de su carpeta `RBR`.

La ubicación prevista en Archivos es:

`En mi iPhone / RBR Mobile / RBR`

o

`En mi iPad / RBR Mobile / RBR`

**Nota:** Según la compilación instalada, la carpeta de la aplicación puede aparecer como `ReRBRProbe` en lugar de `RBR Mobile`. Utiliza la carpeta que realmente aparezca en tu dispositivo.

Copia allí los recursos compatibles obtenidos legítimamente, conservando la estructura original de las carpetas. No cambies los nombres de los archivos ni de los directorios internos.

La lista exacta de recursos necesarios y los métodos de instalación compatibles se documentarán a medida que avancen las pruebas.

### Consideraciones importantes

- Con cuentas gratuitas de Apple puede ser necesario volver a firmar la aplicación aproximadamente cada siete días.
- El rendimiento depende del dispositivo.
- Algunos vehículos y tramos pueden necesitar recursos compatibles adicionales.
- No redistribuyas archivos del juego protegidos por derechos de autor sin autorización.
