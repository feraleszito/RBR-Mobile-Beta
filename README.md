# RBR Mobile — iOS & iPadOS Beta

**Richard Burns Rally on your iPhone and iPad.**

An unofficial community project bringing the legendary PC rally simulator to mobile devices, with a focus on authentic driving physics, responsive controls and smooth performance.

**Current version:** v0.1.0-beta.1 (upcoming release)  
**Platform:** iOS / iPadOS  
**App language:** Spanish 🇨🇱  
**Status:** Public beta preparation

## Features

- Richard Burns Rally driving experience on iPhone and iPad.
- NGP-based vehicle physics.
- Touch controls and gyroscope steering.
- 3D vehicle showroom.
- Engine audio and rally stages.
- Support for compatible vehicle and stage resources.
- Native rendering using Metal.
- Up to 60 FPS, depending on device and scene.

## Language

**The app's interface is currently available in Spanish only.**

English interface support may be considered in future updates. International players are welcome to participate in testing.

## Installation

The beta is distributed as an unsigned IPA.

You will need a compatible iPhone or iPad, a computer to sign and install the IPA (for example, using Sideloadly), and the required game resources obtained from legitimate sources.

Installation instructions will be published in `INSTALLATION.md`.

**Original game resources are not included.**

## Compatibility

Successfully tested on:

- iPhone 15 — 60 FPS reported during testing.
- iPad mini (A17 Pro).

Performance and compatibility may vary across devices.

## Feedback

Found a bug or have a suggestion? Feedback instructions will be provided with the first release.

# RBR Mobile — Beta para iOS y iPadOS

**Richard Burns Rally en tu iPhone y iPad.**

Un proyecto comunitario no oficial que busca llevar el legendario simulador de rally de PC a dispositivos móviles, priorizando las físicas de conducción, los controles y el rendimiento.
